# Aria — AI Workplace Productivity Assistant

Aria is a modern, responsive SaaS-style web application that helps professionals automate everyday workplace tasks using AI. It bundles five focused tools behind a clean dashboard with sidebar navigation, structured prompts, editable AI outputs, and a responsible-AI disclaimer.

## ✨ Features

- **Smart Email Generator** — Draft professional emails with control over recipient, tone, goal, and key points.
- **Meeting Notes Summarizer** — Turn raw transcripts or notes into crisp summaries, decisions, and action items.
- **AI Task Planner** — Break goals into prioritized, time-boxed task lists.
- **AI Research Assistant** — Get structured briefings on any topic with key facts and follow-up questions.
- **AI Chatbot** — Multi-threaded conversational assistant for any workplace question (history persisted in `localStorage`).

### UX requirements covered
- Modern dashboard UI with gradient accents and soft shadows
- Collapsible sidebar navigation (`AppSidebar`)
- Fully responsive layout (mobile → desktop)
- Structured AI prompts per tool (system + user prompt templates)
- Editable AI outputs (toggle between rendered Markdown and editable textarea, copy to clipboard)
- Responsible-AI disclaimer in the sidebar, dashboard, and on every generated output

## 🧱 Tech Stack

- **Framework:** TanStack Start v1 (React 19, SSR, file-based routing)
- **Build tool:** Vite 7
- **Styling:** Tailwind CSS v4 with semantic tokens in `src/styles.css` (light + dark mode, OKLCH palette)
- **UI:** shadcn/ui components, lucide-react icons, sonner toasts
- **AI:** Vercel AI SDK (`ai`, `@ai-sdk/openai-compatible`) streaming through the **Lovable AI Gateway** (`google/gemini-3-flash-preview`)
- **Markdown:** `react-markdown`
- **Runtime:** Edge (Cloudflare Workers compatible)

## 🚀 Getting Started

### Prerequisites
- [Bun](https://bun.sh) (recommended) or Node 20+
- A `LOVABLE_API_KEY` (auto-provisioned in Lovable; for local dev set it in `.env`)

### Install & run
```bash
bun install
bun run dev
```

The app starts on `http://localhost:8080` (or the port Vite picks). Open the dashboard at `/` and pick a tool from the sidebar.

### Environment
| Variable | Purpose |
| --- | --- |
| `LOVABLE_API_KEY` | Server-side key used by `src/lib/ai-gateway.server.ts` to call the Lovable AI Gateway. Never expose to the client. |

## 🤖 How the AI works

- **`/api/generate`** — POST `{ system, prompt }`. Streams plain text back. Used by the four single-shot tools via `AiToolShell`.
- **`/api/chat`** — POST `{ messages }`. Streams chat completions for the multi-thread chatbot.
- Each tool defines its own **system prompt** and constructs a structured **user prompt** from form inputs, so outputs stay consistent and on-task.
- Streamed output renders as Markdown in real time, then becomes editable with one click.

## 🛡️ Responsible AI

Aria's outputs are generated by AI models and may be inaccurate, outdated, or biased. The app displays a disclaimer in the sidebar, on the dashboard, and beneath every generated result. **Always review AI output before sending, sharing, or acting on it**, and avoid pasting confidential data you wouldn't share with a third-party AI provider.
